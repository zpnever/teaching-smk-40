BAGIAN 1 — TUTORIAL: MEMBUAT WEB PORTOFOLIO PRIBADI
Ikuti langkah-langkah berikut untuk membuat halaman web portofolio sederhana. Contoh di bawah ini
menggunakan data “Rangga Pratama” — gantilah dengan foto, nama, dan data kalian sendiri saat
mengerjakan sendiri di rumah/lab.
Langkah 1: Menyiapkan Struktur Folder Project
Langkah kerja:
1. Buat sebuah folder project baru, misalnya diberi nama: portofolio-nama-kalian.
2. Di dalam folder tersebut, buat 2 file kosong: index.html dan style.css.
3. Di dalam folder yang sama, buat 1 folder lagi bernama images/ untuk menyimpan foto profil dan gambar
proyek.
4. Buka folder project tersebut menggunakan Visual Studio Code.
Catatan: CSS akan ditulis secara External (file terpisah dari HTML) agar tampilan dan struktur halaman lebih rapi
dan mudah dirawat.
Langkah 2: Membuat Kerangka Dasar HTML
Langkah kerja:
1. Buka file index.html.
2. Ketik atau salin kode berikut ke dalamnya.
3. Simpan file (Ctrl+S).
index.html
&lt;!DOCTYPE html&gt;
&lt;html lang=&quot;id&quot;&gt;
&lt;head&gt;
&lt;meta charset=&quot;UTF-8&quot;&gt;
&lt;title&gt;Portofolio - Rangga Pratama&lt;/title&gt;
&lt;link rel=&quot;stylesheet&quot; href=&quot;style.css&quot;&gt;
&lt;/head&gt;
&lt;body&gt;
&lt;/body&gt;
&lt;/html&gt;
Baris &lt;link rel=&quot;stylesheet&quot; href=&quot;style.css&quot;&gt; inilah yang menghubungkan file HTML dengan file CSS
eksternal kalian. Semua elemen lain akan kita tambahkan satu per satu di antara tag &lt;body&gt; dan
&lt;/body&gt;.
Langkah 3: Membuat &amp; Mendesain Navbar (Menu Navigasi)
Langkah kerja:
1. Buka index.html, lalu tambahkan kode navbar berikut di dalam &lt;body&gt;.
2. Buka style.css, lalu tambahkan kode styling navbar berikut di bagian paling bawah.

Hasilnya: sebuah navbar biru tua dengan menu berwarna putih akan tampil di bagian paling atas
halaman.
Langkah 4: Membuat &amp; Mendesain Bagian Beranda (Hero Section)
Langkah kerja:
1. Buka index.html, lalu tambahkan bagian Hero berikut tepat di bawah navbar (setelah tag &lt;/header&gt;).
2. Buka style.css, lalu tambahkan kode styling Hero berikut di bagian paling bawah.
3. Simpan kedua file, lalu refresh browser untuk melihat hasilnya.
index.html
&lt;section class=&quot;hero&quot; id=&quot;beranda&quot;&gt;

Langkah 5: Membuat &amp; Mendesain Bagian Tentang Saya
Langkah kerja:
1. Buka index.html, lalu tambahkan bagian Tentang Saya tepat di bawah section Hero.
2. Buka style.css, lalu tambahkan kode styling berikut di bagian paling bawah.
3. Simpan kedua file, lalu refresh browser untuk melihat hasilnya.

di halaman.

Langkah 8: Membuat Bagian Kontak dan Footer
Langkah kerja:
1. Buka index.html, lalu tambahkan bagian Kontak dan Footer di bagian paling bawah, tepat sebelum tag
&lt;/body&gt;.
2. Buka style.css, lalu tambahkan kode styling berikut di bagian paling bawah.
3. Simpan kedua file, lalu refresh browser untuk melihat hasil akhirnya.
index.html
&lt;section class=&quot;kontak&quot; id=&quot;kontak&quot;&gt;
&lt;h2&gt;Hubungi Saya&lt;/h2&gt;
&lt;p&gt;Email: rangga@email.com&lt;/p&gt;
&lt;p&gt;Instagram: @rangga.dev&lt;/p&gt;
&lt;/section&gt;
&lt;footer&gt;
&lt;p&gt;&amp;copy; 2026 Rangga Pratama. Semua hak dilindungi.&lt;/p&gt;
&lt;/footer&gt;
style.css
footer {
background-color: #1F3864;
color: #FFFFFF;
text-align: center;
padding: 16px;
}
.hero, .kontak, .skill {
text-align: center;
}
Selector footer memakai Element/Tag Selector, sedangkan .hero, .kontak, .skill { } memakai Group
Selector — cara menulis satu aturan CSS untuk beberapa selector sekaligus.
Langkah 9: Menguji dan Merapikan Tampilan Akhir
Langkah kerja:
• Buka file index.html di browser, cek satu per satu bagian dari Navbar sampai Footer.
• Pastikan tidak ada elemen yang tumpang tindih akibat padding/margin yang keliru.
• Perhatikan margin collapsing: margin antar section yang saling bersebelahan bisa “menyatu”, bukan
berjumlah — sesuaikan bila jarak terasa kurang/lebih.
• Cek kontras warna teks dan latar agar tetap mudah dibaca.
Catatan: Kalian boleh menambah gaya lain (misalnya font-size atau text-align) untuk mempercantik tampilan,
selama seluruh materi wajib (selector, color, background, box model) tetap terlihat jelas penerapannya.
BAGIAN 2 — SOAL PRAKTIK MANDIRI
Setelah mengikuti tutorial, buatlah web portofolio PRIBADI kalian sendiri (bukan menyalin persis contoh
tutorial di atas) yang menerapkan seluruh materi yang telah dipelajari: HTML Dasar, CSS Dasar (cara
penulisan &amp; selector), CSS Color, CSS Background, dan CSS Box Model.

Halaman 6

☐ Struktur halaman lengkap: Navbar, Beranda/Hero (foto + nama + deskripsi diri), Tentang Saya,
Keahlian (minimal 4 skill), Portofolio/Proyek (minimal 2 proyek dengan gambar &amp; deskripsi), Kontak,
dan Footer.
☐ CSS ditulis secara External (file style.css terpisah dari index.html).
☐ Menggunakan minimal 4 jenis CSS Selector yang berbeda (Element, Class, Id, Descendant,
dan/atau Group Selector).
☐ Menggunakan minimal 4 format penulisan warna yang berbeda (Named Color, HEX, RGB, RGBA,
HSL).
☐ Menerapkan CSS Background pada minimal 2 elemen berbeda; minimal satu di antaranya memakai
background-image lengkap dengan background-repeat, background-position, dan background-size.
☐ Menerapkan CSS Box Model secara sadar: tentukan box-sizing (content-box/border-box) beserta
alasannya, atur padding &amp; margin konsisten antar bagian, gunakan properti border pada minimal 2
elemen, terapkan border-radius pada minimal 2 elemen (mis. foto profil, tombol, atau kartu), dan
terapkan outline pada elemen interaktif (tautan/tombol saat :hover atau :focus).
☐ Melampirkan laporan singkat (maksimal 1 halaman) yang berisi: daftar selector yang dipakai beserta
lokasinya, daftar format warna yang dipakai beserta lokasinya, dan alasan pemilihan box-sizing.
