Mengapa menggunakan tag ini?

Contoh HTML semantik

Apa bedanya?

Tampilan sama, maknanya berbeda

Browser dapat menampilkan keduanya dengan bentuk yang sama. Perbedaannya ada pada makna struktur di dalam kode.

Tag semantik

<header>, <main>, dan tag sejenis langsung menjelaskan peran konten.

  • Kode lebih mudah dibaca dan dipelihara
  • Membantu pembaca layar memahami struktur
  • Memudahkan mesin pencari mengenali isi halaman

Tag div

<div> adalah wadah umum. Maknanya baru terlihat jika kita membaca nama class atau id.

  • Tepat untuk pengelompokan yang tidak punya tag khusus
  • Berguna sebagai pembungkus untuk styling atau layout
  • Jangan gunakan div jika sudah ada tag yang lebih bermakna
💡

Ingat: pilih tag berdasarkan arti kontennya, bukan warna atau posisinya. CSS mengatur tampilan; HTML menjelaskan struktur dan makna.
