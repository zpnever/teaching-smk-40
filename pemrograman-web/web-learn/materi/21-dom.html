DOM: Mengubah Halaman Web dari JavaScript

Selama ini hasil kodemu hanya muncul di Console, yang cuma dilihat developer. Sekarang JavaScript akan mengubah tulisan, warna, dan isi halaman yang dilihat pengguna — bahkan saat pengguna mengklik tombol.

Setelah ini kamu bisa:

  • Menjelaskan apa itu DOM dan memilih elemen dengan querySelector
  • Mengubah isi (textContent, innerHTML), tampilan (style, classList), dan atribut
  • Membuat & menghapus elemen dengan createElement, append, remove
  • Memicu perubahan saat tombol diklik (pengenalan singkat addEventListener)
Mulai Belajar
HTML + CSS + JS bersatu
Daftar Isi
1

PengenalanSetup & Apa Itu DOM?

Selama ini JavaScript kita hanya menampilkan hasil di Console. Bagaimana caranya mengubah tulisan, warna, dan isi halaman web yang dilihat pengguna langsung dari JavaScript? Jawabannya: DOM Manipulation — titik di mana HTML, CSS, dan JavaScript akhirnya bersatu.
DefinisiDOM (Document Object Model) adalah representasi halaman HTML dalam bentuk pohon objek yang dibuat browser, sehingga JavaScript bisa membaca dan mengubah isi halaman.
Setup: HTML & CSS disediakan

Kali ini kita memakai satu halaman HTML dan satu file CSS yang sudah jadi. Kamu hanya menulis script.js. Di editor di bawah, buka tab index.html dan style.css untuk melihat isinya (bertanda gembok = tidak perlu diubah), lalu lihat hasilnya di Preview.

Tag <script> diletakkan di bawah sebelum </body> agar semua elemen sudah ada saat JavaScript berjalan. Dan setiap kali halaman di-refresh, halaman kembali seperti semula — DOM hanya berubah di memori browser, bukan di file HTML-mu.
Halaman = pohon
document

           ├── h1#judul

Setiap elemen HTML di JavaScript adalah sebuah object (pertemuan 20). Elemen punya property (textContent, style, …) dan method (remove(), append(), …).
Di browser asli, buka F12 → tab Elements untuk melihat pohon DOM halamanmu. Saat JavaScript mengubah sesuatu, tab Elements ikut berubah secara langsung.

Langkah PertamaMemilih Elemen

Sebelum mengubah elemen, kita harus memilihnya terlebih dahulu.

Method Hasil
getElementById("judul") Satu elemen (tanpa #)
querySelector("#judul") Satu elemen pertama yang cocok
querySelectorAll(".deskripsi") Daftar semua elemen yang cocok (akses lewat index, ada length)
Selector sama dengan CSS
Selector Memilih
"#judul" Elemen dengan id="judul"
".deskripsi" Elemen dengan class="deskripsi"
"p" Semua tag <p>
"#daftar li" Semua <li> di dalam #daftar
"input[type='text']" Tambahan: selector atribut, sama seperti di CSS
Rekomendasi: pakai querySelector dan querySelectorAll sebagai kebiasaan utama, karena selector-nya sama dengan CSS yang sudah kamu kuasai. Jika elemen tidak ditemukan, hasilnya adalah null.

textContent: mengubah teks biasa

Coba hapus // di baris ketiga, lalu jalankan lagi. Bandingkan tampilan kotak di Preview.

textContent innerHTML

Aturan praktis

Pakai textContent jika hanya mengubah teks. Pakai innerHTML hanya jika memang perlu menyisipkan tag HTML, dan jangan memasukkan input pengguna langsung ke innerHTML — orang iseng bisa menyisipkan kode berbahaya.

Mengubah Tampilanstyle & classList

1) style: mengubah CSS langsung
Aturan penulisan style Salah ❌ Benar ✅
Nama property ditulis camelCase (tanpa -) style.background-color style.backgroundColor
Nilai berupa string style.fontSize = 24 style.fontSize = "24px"
Satuan wajib ditulis "24" "24px"
2) classList: mengelola class (lebih rapi)

Class aktif, besar, dan sembunyi sudah dibuat di style.css (cek tab-nya).

Method Fungsi
add("x") Menambahkan class x
remove("x") Menghapus class x
toggle("x") Bolak-balik: ditambah jika belum ada, dihapus jika sudah ada
contains("x") Mengecek apakah class x ada (true/false)
Tulis nama class tanpa titik: add("aktif"), bukan add(".aktif").

classList (disarankan)

Aturan tampilan tetap di CSS; JavaScript hanya menentukan kapan class dipakai.

style

Cocok untuk nilai yang dihitung program, misalnya lebar dari angka: bar.style.width = persen + "%".

Teknik Dark Mode yang dulu kamu copy-paste sebenarnya hanyalah document.body.classList.toggle("dark-mode"). Sekarang kamu paham maksud baris itu!
5

Mengubah AtributgetAttribute & setAttribute

Atribut adalah bagian di dalam tag HTML, misalnya href, placeholder, src, id.

Klik tautannya di Preview: Console akan memberi tahu ke mana tautan itu menuju.

Method Fungsi
getAttribute("nama") Membaca nilai atribut
setAttribute("nama", "nilai") Mengubah/menambah atribut
removeAttribute("nama") Menghapus atribut
Tambahan: property langsung & dataset

Atribut umum juga tersedia sebagai property, jadi bisa ditulis lebih singkat. Untuk atribut buatan sendiri, HTML menyediakan data-* yang dibaca lewat dataset.

6

Mengubah StrukturMembuat & Menghapus Elemen

Buat → isi → masukkan
Membuat elemen baru: 3 langkah
Elemen yang baru dibuat belum tampil di halaman sampai dimasukkan dengan append atau prepend.
Method Fungsi
createElement("tag") Membuat elemen baru (belum tampil)
induk.append(elemen) Memasukkan elemen di akhir induk
induk.prepend(elemen) Memasukkan elemen di awal induk
elemen.remove() Menghapus elemen dari halaman
Menghapus elemen
append/prepend mirip push/unshift pada array, sedangkan remove() mirip menghapus elemen. Bedanya, di sini yang berubah adalah tampilan halaman.
Tambahan: menyisipkan di posisi lain
7

InteraksiMemicu Perubahan dengan Klik

Semua perubahan tadi terjadi otomatis saat halaman dibuka. Agar perubahan terjadi saat pengguna melakukan sesuatu (misalnya klik tombol), kita pakai event listener.

const tombol = document.querySelector("#tombol1");

tombol.addEventListener("click", () => {
  // kode di sini dijalankan SETIAP KALI tombol diklik
});

Bagian () => { ... } adalah arrow function yang sudah kamu pelajari. Function ini tidak dipanggil langsung, tetapi dijalankan browser saat tombol diklik — inilah callback dari pertemuan 19.

Contoh: penghitung klik

Klik Tombol 1 di Preview berkali-kali. Variabel hitung dibuat di luar function agar nilainya tetap tersimpan di antara klik (ingat materi scope).

Hari ini event cukup dipakai sebagai pola siap pakai. Jenis-jenis event, event object e, form & preventDefault, sampai event delegation dibahas lengkap di pertemuan 22 — Event.

DebuggingKesalahan Umum & Latihan C

No Kesalahan Akibat Perbaikan
1 Selector salah: querySelector("judul") (lupa # atau .) Hasil null, lalu TypeError: Cannot set properties of null querySelector("#judul")
2 <script> diletakkan sebelum elemennya dibuat Elemen tidak ditemukan (null) Letakkan <script> di bawah <body> (atau defer)
3 Memperlakukan querySelectorAll seperti satu elemen: semua.textContent = "x" Tidak ada perubahan di halaman semua[0].textContent = "x" atau forEach
4 style.background-color = "red" SyntaxError style.backgroundColor = "red"
5 style.fontSize = 24 (tanpa satuan, bukan string) Tidak berpengaruh style.fontSize = "24px"
6 classList.add(".aktif") (pakai titik) Class bernama .aktif ditambahkan, tidak ada efek classList.add("aktif")
7 Elemen dibuat tapi lupa dimasukkan Tidak tampil di halaman Tambahkan append() atau prepend()
8 addEventListener("click", sapa()) Function langsung jalan, klik tidak bekerja addEventListener("click", sapa)

Kesalahan nomor 2 bisa kamu lihat sendiri: di editor ini script dipindah ke <head>. Jalankan dan baca error-nya, lalu perbaiki dengan memindahkan baris <script> ke bawah body (atau tambahkan defer).

RingkasRangkuman (Contekan)

DOM
// MEMILIH
document.getElementById("judul");
document.querySelector("#kotak");          // satu
document.querySelectorAll(".deskripsi");   // banyak → [0], .length

// TEKS
el.textContent = "teks biasa";
el.innerHTML = "teks <b>dengan tag</b>";

// TAMPILAN
el.style.backgroundColor = "tomato";       // camelCase, string + satuan
el.classList.add("aktif");
el.classList.remove("aktif");
el.classList.toggle("aktif");
el.classList.contains("aktif");            // true/false

// ATRIBUT
el.getAttribute("href");
el.setAttribute("href", "https://...");
el.removeAttribute("href");

// MEMBUAT & MENGHAPUS
const baru = document.createElement("li");
baru.textContent = "Isi";
induk.append(baru);                        // akhir
induk.prepend(baru);                       // awal
el.remove();
Klik (pola siap pakai)
tombol.addEventListener("click", () => {
  // dijalankan SETIAP KALI tombol diklik
});

// ✅ kirim function-nya
tombol.addEventListener("click", sapa);
// ❌ sapa() langsung jalan sekarang
tombol.addEventListener("click", sapa());
Event lengkap (input, submit, keydown, e.target, delegation) ada di pertemuan 22.

Pola kerja DOM

  1. Pilih elemennya (querySelector) — cek tidak null.
  2. Dengarkan event-nya (addEventListener) bila perubahan harus menunggu aksi pengguna.
  3. Ubah isi / class / atribut / struktur di dalam callback.
