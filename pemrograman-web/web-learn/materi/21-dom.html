DOM: Mengubah Halaman Web dari JavaScript

Selama ini hasil kodemu hanya muncul di Console, yang cuma dilihat developer. Sekarang JavaScript akan mengubah tulisan, warna, dan isi halaman yang dilihat pengguna — dan bereaksi saat pengguna mengklik, mengetik, atau mengirim form.

Setelah ini kamu bisa:

  • Menjelaskan apa itu DOM dan memilih elemen dengan querySelector
  • Mengubah isi (textContent, innerHTML), tampilan (style, classList), dan atribut
  • Membuat & menghapus elemen dengan createElement, append, remove
  • Memakai event yang sering dipakai: click, input, change, submit, keydown, mouseenter, dll.
  • Membaca input form, memakai e.target, preventDefault, dan event delegation

PengenalanSetup & Apa Itu DOM?

Selama ini JavaScript kita hanya menampilkan hasil di Console. Bagaimana caranya mengubah tulisan, warna, dan isi halaman web yang dilihat pengguna langsung dari JavaScript? Jawabannya: DOM Manipulation — titik di mana HTML, CSS, dan JavaScript akhirnya bersatu.
DefinisiDOM (Document Object Model) adalah representasi halaman HTML dalam bentuk pohon objek yang dibuat browser, sehingga JavaScript bisa membaca dan mengubah isi halaman.
Setup: HTML & CSS disediakan

Kali ini kita memakai satu halaman HTML dan satu file CSS yang sudah jadi. Kamu hanya menulis script.js. Di editor di bawah, buka tab index.html dan style.css untuk melihat isinya (bertanda gembok = tidak perlu diubah), lalu lihat hasilnya di Preview.

Tag <script> diletakkan di bawah sebelum </body> agar semua elemen sudah ada saat JavaScript berjalan. Dan setiap kali halaman di-refresh, halaman kembali seperti semula — DOM hanya berubah di memori browser, bukan di file HTML-mu.

Setiap elemen HTML di JavaScript adalah sebuah object (pertemuan 20). Elemen punya property (textContent, style, …) dan method (remove(), append(), …).
Di browser asli, buka F12 → tab Elements untuk melihat pohon DOM halamanmu. Saat JavaScript mengubah sesuatu, tab Elements ikut berubah secara langsung.

Pakai textContent jika hanya mengubah teks. Pakai innerHTML hanya jika memang perlu menyisipkan tag HTML, dan jangan memasukkan input pengguna langsung ke innerHTML — orang iseng bisa menyisipkan kode berbahaya.

InteraksiMemicu Perubahan dengan Klik

Semua perubahan tadi terjadi otomatis saat halaman dibuka. Agar perubahan terjadi saat pengguna melakukan sesuatu (misalnya klik tombol), kita pakai event listener.

const tombol = document.querySelector("#tombol1");

tombol.addEventListener("click", () => {
  // kode di sini dijalankan SETIAP KALI tombol diklik
});

Bagian () => { ... } adalah arrow function yang sudah kamu pelajari. Function ini tidak dipanggil langsung, tetapi dijalankan browser saat tombol diklik — inilah callback dari pertemuan 19.

Contoh: penghitung klik

Klik Tombol 1 di Preview berkali-kali. Variabel hitung dibuat di luar function agar nilainya tetap tersimpan di antara klik (ingat materi scope).

EventAnatomi Event & Event Object

Tambahan
EventSesuatu yang terjadi di halaman: tombol diklik, tombol keyboard ditekan, isi input berubah, form dikirim, halaman selesai dimuat. JavaScript bisa "mendengarkan" event dan menjalankan function saat event itu terjadi.
elemen.addEventListener("jenisEvent", callback);
//       ↑ siapa yang didengar   ↑ apa      ↑ function yang dijalankan
Callback dikirim, bukan dipanggil

Coba hapus // di baris terakhir: "Halo!" langsung muncul tanpa diklik, dan kliknya tidak bekerja dengan benar. Ini kesalahan yang sangat sering terjadi!

Event object: informasi tentang kejadiannya

Browser mengirim sebuah object ke callback — biasanya dinamai e atau event. Isinya informasi tentang event tersebut.

Property / methodIsinya
e.typeJenis event: "click", "input", …
e.targetElemen yang memicu event (yang benar-benar diklik/diketik)
e.currentTargetElemen yang dipasangi listener
e.keyTombol keyboard yang ditekan (khusus event keyboard)
e.preventDefault()Mencegah aksi bawaan browser (misalnya form reload, tautan pindah halaman)
e.stopPropagation()Menghentikan event agar tidak "naik" ke elemen induk
Melepas listener & onclick
Biasakan memakai addEventListener. removeEventListener hanya bisa melepas function yang punya nama (arrow function tanpa nama tidak bisa dilepas).

DOMContentLoaded & defer

Kalau <script> terpaksa diletakkan di <head>, elemen di body belum ada saat kode berjalan. Ada dua solusi: bungkus kode dengan event DOMContentLoaded, atau beri atribut defer. Lihat tab index.html: script-nya ada di head!

EventMembaca Input & Mengolah Form

Tambahan
ElemenMembaca nilainyaCatatan
<input>, <textarea>el.valueSelalu string — termasuk type="number"
<select>el.valueNilai option yang dipilih
checkbox / radioel.checkedtrue / false
"5" + "7" = "57", bukan 12! Ubah dulu dengan Number(input.value) sebelum menghitung. Dan pakai .trim() untuk membuang spasi di awal/akhir sebelum mengecek apakah input kosong.
submit & preventDefault

Aksi bawaan form adalah mengirim data lalu memuat ulang halaman — semua perubahan DOM hilang. Karena itu listener submit hampir selalu diawali e.preventDefault(). Coba beri // pada baris e.preventDefault() lalu kirim form: Console memperingatkan dan halaman dimuat ulang.

Memakai event submit pada <form> (bukan click pada tombol) lebih baik: form juga terkirim saat pengguna menekan Enter di dalam input.

Tambahan
Mengolah semua hasil querySelectorAll

querySelectorAll menghasilkan NodeList yang bisa diulang dengan forEach atau for...of (pertemuan 20).

Begitulah cara aplikasi sungguhan menampilkan data: data dari server (array of object) diulang, lalu setiap item dijadikan elemen HTML.
Bubbling: event naik ke induk
Event delegation: satu listener untuk banyak anak

Daripada memasang listener ke setiap <li> (termasuk yang dibuat belakangan), pasang satu listener di induknya. Dari e.target kita tahu anak mana yang diklik; closest("li") mencari li terdekat ke atas.

RingkasRangkuman (Contekan)

DOM
// MEMILIH
document.getElementById("judul");
document.querySelector("#kotak");          // satu
document.querySelectorAll(".deskripsi");   // banyak → [0], .length

// TEKS
el.textContent = "teks biasa";
el.innerHTML = "teks <b>dengan tag</b>";

// TAMPILAN
el.style.backgroundColor = "tomato";       // camelCase, string + satuan
el.classList.add("aktif");
el.classList.remove("aktif");
el.classList.toggle("aktif");
el.classList.contains("aktif");            // true/false

// ATRIBUT
el.getAttribute("href");
el.setAttribute("href", "https://...");
el.removeAttribute("href");

// MEMBUAT & MENGHAPUS
const baru = document.createElement("li");
baru.textContent = "Isi";
induk.append(baru);                        // akhir
induk.prepend(baru);                       // awal
el.remove();
Event
// POLA DASAR
tombol.addEventListener("click", (e) => {
  // dijalankan setiap klik
  console.log(e.target);
});

// YANG SERING DIPAKAI
"click"  "dblclick"  "mouseenter"  "mouseleave"
"keydown" (e.key)    "input"       "change"
"focus"  "blur"      "submit"      "DOMContentLoaded"

// FORM
form.addEventListener("submit", (e) => {
  e.preventDefault();                      // jangan reload
  const n = Number(input.value.trim());
});

// BANYAK ELEMEN
document.querySelectorAll("li").forEach((li) => { ... });

// DELEGATION
daftar.addEventListener("click", (e) => {
  const li = e.target.closest("li");
  if (!li) return;
});

Pola kerja DOM

  1. Pilih elemennya (querySelector) — cek tidak null.
  2. Dengarkan event-nya (addEventListener) bila perubahan harus menunggu aksi pengguna.
  3. Ubah isi / class / atribut / struktur di dalam callback.
