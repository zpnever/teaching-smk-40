PengenalanApa Itu JavaScript?

JS membuat web hidup
DefinisiJavaScript (JS) adalah bahasa pemrograman yang berjalan di browser (dan juga di server lewat Node.js) yang digunakan untuk membuat halaman web menjadi dinamis dan interaktif.
Yang bisa dilakukan JavaScript

1Merespons pengguna

Bereaksi saat tombol diklik, teks diketik, atau mouse digerakkan.

2Mengubah halaman

Mengganti isi & tampilan secara langsung tanpa reload.

3Validasi form

Misalnya mengecek email yang diisi valid atau tidak.

4Ambil data server

Mengambil data dari API: cuaca, berita, jadwal, dll.

5Game & aplikasi

Membuat game, animasi kompleks, sampai aplikasi web lengkap.

SetupMenghubungkan JavaScript ke HTML

HTML memanggil script.js

Ada 3 cara menaruh JavaScript di halaman HTML. Klik tiap tab untuk melihat contohnya.

Inline — langsung di atribut tag HTML. Tidak disarankan: kode bercampur dengan HTML dan sulit dirawat.

Internal — di dalam tag <script> pada file HTML. Lumayan untuk kode pendek.

Eksternal — file .js terpisah. Paling disarankan: HTML tetap rapi dan satu file JS bisa dipakai banyak halaman.

Posisi tag <script>

Letakkan di bagian bawah <body>. Alasannya: browser membaca HTML dari atas ke bawah. Jika script diletakkan di atas sebelum elemen HTML selesai dimuat, script bisa gagal menemukan elemen tersebut (akan sangat terasa nanti saat belajar DOM).

Ada cara lain: taruh script di <head> tapi tambahkan atribut defer, misalnya <script src="script.js" defer></script>. Browser akan menunggu HTML selesai dibaca sebelum menjalankan script.
Setup praktik

Buat sebuah folder proyek berisi 2 file: index.html dan script.js. Buka index.html di browser, tekan F12 → tab Console. Jika muncul tulisan Halo, JavaScript!, berarti JavaScript kalian sudah berjalan.

Di website ini kamu tidak perlu repot membuat file: setiap kotak kode bertanda script.js bisa langsung kamu ubah dan jalankan. Output-nya muncul di panel Console di bawah editor.

3

Outputconsole.log() & Komentar

Tambahan
Menampilkan output

console.log() menampilkan isi di dalam kurungnya ke tab Console. Ini alat paling penting untuk melihat apa yang terjadi di dalam program. Boleh menampilkan beberapa nilai sekaligus, dipisah koma.

Komentar

Komentar adalah catatan untuk manusia — tidak dijalankan oleh JavaScript. Pakai untuk menjelaskan kode atau "mematikan" baris sementara.

Shortcut di VS Code: blok beberapa baris lalu tekan Ctrl + / (Mac: Cmd + /) untuk menjadikannya komentar sekaligus.

VariabelApa Itu Variabel? & let

Variabel = kotak berlabel
DefinisiVariabel adalah "wadah bernama" untuk menyimpan data di dalam memori komputer, sehingga data tersebut bisa dipakai dan diubah berkali-kali dalam program.

Bayangkan variabel seperti kotak berlabel: label → nama variabel, isi kotak → nilai yang disimpan.

Mendeklarasikan variabel: let

let digunakan untuk membuat variabel yang nilainya boleh diubah di kemudian hari.

BagianContohArtinya
Kata kunci deklarasilet"Tolong buatkan kotak baru"
Nama variabelnamaLabel kotaknya
Operator penugasan="Masukkan ke dalam kotak" (bukan sama dengan!)

Saat mengubah nilai, jangan tulis let lagi. let nama = "Andi"; untuk kedua kalinya akan error karena kotak bernama nama sudah ada. Cukup nama = "Andi";

Variabelconst & Kapan Pakai let vs const

let bisa diubah, const terkunci
Mendeklarasikan variabel: const

const (constant) digunakan untuk variabel yang nilainya tidak boleh diubah setelah ditetapkan. Jalankan kode di bawah dan lihat error-nya!

Console akan menampilkan error: Uncaught TypeError: Assignment to constant variable.

Kapan pakai let vs const?
GunakanKetika
constNilai tidak akan berubah (nama sekolah, nilai PI, konfigurasi)
letNilai akan berubah (skor game, counter, input pengguna)

Best practice

Gunakan const sebagai default, dan ganti menjadi let hanya jika nilainya memang perlu diubah.

Di tutorial lama kamu akan sering melihat var nama = "Budi";. var adalah cara lama (sebelum 2015) yang punya beberapa perilaku membingungkan, misalnya boleh dibuat dua kali dengan nama sama tanpa error. Sekarang cukup pakai let dan const.
6

VariabelAturan Penamaan Variabel

Beri nama yang jelas

Aturan wajib error jika dilanggar

  1. Boleh diawali huruf, _ (underscore), atau $
  2. Tidak boleh diawali angka
  3. Tidak boleh mengandung spasi
  4. Tidak boleh memakai kata kunci JS (let, const, if, dll.)
  5. Case-sensitive: nama dan Nama adalah dua variabel berbeda

Konvensi kesepakatan developer

  • Gunakan camelCase: namaLengkap, totalHarga, jumlahSiswa
  • Nama harus bermakna: umur lebih baik daripada x
  • Konstanta bernilai tetap boleh HURUF_BESAR: const PI = 3.14;

Coba juga di editor: hapus tanda // di salah satu baris lalu jalankan untuk melihat error-nya.

8

Tipe DataNumber, Boolean, undefined & null

Tipe data: number

Number di JavaScript tidak dibedakan bulat/desimal/negatif — semuanya masuk ke dalam tipe data number.

Ada dua nilai number yang unik: NaN (Not a Number, hasil hitungan yang tidak masuk akal seperti "abc" * 2) dan Infinity (misalnya 10 / 0). Anehnya, typeof NaN tetap "number"!
Tipe data: boolean

Hanya punya dua nilai: true atau false. Sangat penting untuk logika program — nanti dipakai di percabangan (pertemuan 17).

Tipe data: undefined & null
undefinednull
ArtinyaBelum diberi nilaiSengaja "kosong"
Diberikan olehJavaScript otomatisProgrammer
Gelas undefined = gelas yang belum pernah diisi apa-apa. Gelas null = gelas yang sengaja dikosongkan dan diberi tulisan "kosong".

Tipe DataOperator typeof

typeof mengecek tipe

typeof digunakan untuk mengecek tipe data dari sebuah nilai/variabel. Hasilnya berupa string.

typeof null menghasilkan "object". Ini adalah bug historis JavaScript sejak 1995 yang tidak pernah diperbaiki demi menjaga kompatibilitas.
