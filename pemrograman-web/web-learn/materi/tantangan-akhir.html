Gabungan #15 – #19

Tantangan Akhir

Lima level koding yang memakai semua yang sudah kamu pelajari: variabel, operator, percabangan, perulangan, dan function. Kalahkan boss-nya, lalu tutup dengan kuis campuran!

Yang diuji:

  • Menulis function dengan parameter dan return
  • Memakai operator aritmatika, perbandingan, logika, dan ternary
  • Menyusun if / else if dengan urutan yang benar
  • Memakai pola akumulator dan nested loop

AturanCara Main

1Baca soal

Setiap level meminta kamu melengkapi sebuah function. Perhatikan nama function dan parameternya — harus sama persis.

2Coba jalankan

Tekan Jalankan untuk melihat output-mu sendiri. Tambahkan console.log untuk mengecek hasil.

3Periksa

Periksa Jawaban menguji function-mu dengan banyak data sekaligus, termasuk kasus batas.

Penilaian

Nilai Tantangan Akhir = 50% kuis campuran + 50% level yang lulus. Level yang kamu selesaikan setelah membuka Lihat Solusi tidak mendapat poin — jadi pakai Petunjuk dulu kalau buntu.
