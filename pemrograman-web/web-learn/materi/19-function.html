Function: Mesin Kecil di Dalam Kode

Tulis sekali, pakai berkali-kali. Function membungkus sekumpulan perintah menjadi satu "mesin" bernama yang bisa menerima input dan mengembalikan hasil.

Setelah ini kamu bisa:

  • Membuat dan memanggil function
  • Memakai parameter dan argument
  • Memakai return dan membedakannya dengan console.log()
  • Menulis arrow function dan default parameter
  • Memahami scope (variabel lokal dan global)
Mulai Belajar
Input masuk, hasil keluar
Daftar Isi
1

PengenalanApa Itu Function?

Satu resep, banyak hasil
DefinisiFunction adalah blok kode bernama yang berisi sekumpulan perintah untuk menyelesaikan satu tugas tertentu, dan bisa dipanggil berulang kali kapan pun dibutuhkan.
Analogi

1Resep masakan

Resep ditulis sekali. Setiap kali ingin masak, cukup "panggil" resepnya — tidak perlu menulis ulang langkah-langkahnya.

2Mesin jus

Masukkan buah (input), mesin bekerja, keluar jus (output). Buah berbeda → jus berbeda, mesinnya tetap sama.

3Tombol lift

Tekan tombol "3", lift menjalankan banyak langkah rumit. Kamu cukup tahu nama tombolnya.

Kenapa butuh function?
  • Tidak mengulang kode (prinsip DRY — Don't Repeat Yourself).
  • Mudah diperbaiki: cukup ubah di satu tempat, semua pemanggil ikut berubah.
  • Kode lebih rapi: program besar dipecah jadi tugas-tugas kecil bernama jelas.
Kamu sudah memakai function sejak pertemuan 15! console.log(), Number(), dan String() adalah function bawaan JavaScript. Sekarang saatnya membuat function sendiri.

InputParameter & Argument

Argument mengisi parameter

Function sapa() selalu menampilkan kalimat yang sama. Bagaimana kalau kita ingin menyapa nama yang berbeda-beda? Solusinya pakai parameter.

Parameter

Variabel penampung yang ditulis di dalam tanda kurung saat membuat function.

Argument

Nilai sebenarnya yang dikirim saat function dipanggil.

nama adalah parameter. "Budi", "Ani", dan "Citra" adalah argument.

Parameter lebih dari satu

Pisahkan dengan koma. Urutan argument harus sama dengan urutan parameter.

Argument yang tidak diisi akan bernilai undefined. Dan JavaScript tidak tahu kalau urutannya tertukar — ia hanya mengisi parameter sesuai urutan.

Gaya PenulisanArrow Function & Default Parameter

Arrow = cara singkat
Arrow function (penulisan ringkas)

Arrow function memakai tanda panah =>. Hasilnya sama, tulisannya lebih pendek.

Di slide, ketiga contoh memakai nama yang sama (kali). Di editor ini namanya dibedakan (kaliArrow, kaliSingkat) supaya bisa dijalankan bersamaan — ingat, satu nama hanya boleh dibuat sekali!
Arrow function singkat (tanpa kurawal) otomatis me-return. Tapi kalau memakai kurawal { }, kamu wajib menulis return sendiri.
Default parameter (nilai bawaan)

Parameter bisa diberi nilai bawaan. Nilai ini dipakai kalau argument-nya tidak diisi — jadi tidak muncul undefined.

7

JangkauanScope: Variabel Lokal & Global

Yang di dalam tak terlihat dari luar

Scope menentukan di mana variabel bisa diakses. Variabel yang dibuat di dalam function hanya hidup di dalam function itu.

Global

Dibuat di luar function. Bisa diakses di mana saja, termasuk dari dalam function.

Lokal

Dibuat di dalam function. Hanya bisa diakses di dalam function itu.

Bayangkan setiap function boleh mengubah semua variabel sesukanya — program besar akan kacau. Scope membuat tiap function punya "kamar" sendiri, jadi nama variabel di dalamnya tidak bentrok dengan yang di luar.
8

Kerja SamaFunction Memanggil Function & Early Return

Tambahan
Kecil-kecil, saling bantu
Function di dalam function

Program yang rapi terdiri dari function-function kecil yang masing-masing punya satu tugas. Hasil return satu function bisa langsung menjadi argument function lain.

Early return

Karena return langsung menghentikan function, kita bisa memakainya untuk keluar lebih awal saat menemukan kasus khusus. Hasilnya: if-else bersarang berkurang dan kode lebih mudah dibaca.

9

Jembatan ke DOMCallback: Function sebagai Argument

Tambahan
Dipanggil balik nanti

Function juga sebuah nilai, jadi bisa dikirim sebagai argument ke function lain. Function yang dikirim dengan cara ini disebut callback — "nanti tolong panggil balik function ini ya".

Callback yang dipanggil nanti: setTimeout

setTimeout(callback, waktu) adalah function bawaan yang memanggil callback setelah sekian milidetik. Jalankan, lalu perhatikan urutan output-nya!
