Event: Halaman yang Bereaksi

Di materi DOM, perubahan halaman terjadi sendiri saat halaman dibuka. Sekarang halamannya akan menunggu pengguna: bereaksi saat tombol diklik, kursor lewat, huruf diketik, pilihan diganti, dan form dikirim.

Setelah ini kamu bisa:

  • Menjelaskan konsep event, listener, dan handler
  • Memasang event dengan addEventListener dan membedakan sapa vs sapa()
  • Memakai click, dblclick, mouseover, mouseout, input, change, keydown, submit
  • Memakai event object: event.target, event.type, event.key
  • Membaca input, select, checkbox (.value, .checked) dan menangani form dengan preventDefault()

Memasang EventaddEventListener

elemen.addEventListener("jenisEvent", handler);
Contoh pertama

Kode di dalam { } tidak langsung dijalankan. Ia hanya dijalankan setiap kali tombol diklik. Klik Tombol 1 di Preview.

Dua cara menulis handler

1. Arrow function langsung (inline)

tombol1.addEventListener("click", () => {
  judul.textContent = "Tombol 1 diklik!";
});

2. Function bernama — cocok jika handler dipakai ulang

function tampilkanPesan() {
  judul.textContent = "Tombol 1 diklik!";
}

tombol1.addEventListener("click", tampilkanPesan);  // ✅ tanpa kurung
⚠️ Memasang vs memanggil (kesalahan nomor satu)
Pada addEventListener, tulis nama function tanpa kurung. Kita hanya menyerahkan function ke browser agar dijalankan nanti, bukan menjalankannya sekarang. Coba tukar komentar di dua baris terakhir lalu jalankan: judul langsung berubah tanpa diklik, dan kliknya tidak berefek.
Variabel di luar handler

Variabel yang nilainya harus tersimpan di antara klik dibuat di luar handler (ingat materi scope).

Tambahan: melepas listener & onclick
Biasakan memakai addEventListener. removeEventListener hanya bisa melepas function yang punya nama.

Informasi KejadianEvent Object

Saat event terjadi, browser otomatis mengirim sebuah object berisi informasi tentang kejadian tersebut ke handler. Object ini disebut event object, biasa dinamai event atau e. Klik Tombol 1 di Preview dan lihat Console.

Properti / MethodIsi
event.typeJenis event ("click", "input", ...)
event.targetElemen tempat event terjadi
event.keyTombol keyboard yang ditekan (khusus keydown)
event.preventDefault()Mencegah perilaku bawaan browser (dipakai di form)
Event object adalah object biasa, persis seperti di materi Array & Object. Kita membaca isinya dengan titik: event.target.
Satu handler untuk banyak elemen

e.target memberi tahu tombol mana yang sedang diklik, sehingga satu function cukup untuk ketiga tombol.

Formsubmit & preventDefault()

Saat tombol Daftar diklik, browser secara bawaan mengirim form dan memuat ulang halaman. Akibatnya semua perubahan di halaman hilang.

Solusinya event.preventDefault(). Coba beri // pada baris e.preventDefault(); lalu klik Daftar: Console memperingatkan bahwa halaman akan dimuat ulang.

Pasang submit pada <form>, bukan pada tombolnya. Dengan begitu form juga bisa dikirim dengan menekan Enter.
Cek isi input dengan if, lalu tampilkan pesan di halaman (bukan hanya di Console).
Tambahan: form dengan beberapa isian

Form ini (halaman berbeda) membaca teks, angka, dan select sekaligus. Perhatikan .trim() (membuang spasi di awal/akhir), Number(), dan form.reset().

EventBanyak Elemen, Delegation & Bubbling

Tambahan
Pasang listener ke semua hasil querySelectorAll

Di bagian 4, ketiga tombol dipasang satu per satu. Dengan forEach (pertemuan 20) cukup sekali. Ingat: querySelectorAll menghasilkan daftar, dan daftar tidak punya addEventListener.

Event delegation: satu listener untuk banyak anak

Item tugas dibuat belakangan, setelah kode berjalan. Daripada memasang listener ke setiap <li>, pasang satu listener di induknya. Dari e.target kita tahu anak mana yang diklik; closest("li") mencari li terdekat ke atas.

Bubbling: kenapa delegation bisa bekerja

Setelah terjadi di target, event naik (bubbling) ke induknya, lalu ke induknya lagi, sampai document.

RingkasRangkuman (Contekan)

Pola
// POLA DASAR
elemen.addEventListener("click", () => {
  // kode dijalankan setiap kali elemen diklik
});

// FUNCTION BERNAMA (tanpa kurung saat dipasang!)
function handler() { /* ... */ }
elemen.addEventListener("click", handler);

// EVENT OBJECT
elemen.addEventListener("click", (e) => {
  e.type;        // "click"
  e.target;      // elemen yang terkena event
  e.key;         // tombol keyboard (untuk keydown)
  e.preventDefault();
});
Input & form
// INPUT
input.addEventListener("input", () => { input.value; });   // string
select.addEventListener("change", () => { select.value; });
checkbox.addEventListener("change", () => { checkbox.checked; });
tombol.disabled = true;

// FORM
form.addEventListener("submit", (e) => {
  e.preventDefault();
  // validasi & tampilkan pesan
});

Porsi UtamaLatihan A & B

Latihan A — Tebak hasil

Semua soal memakai halaman pada bagian 1. Di editor ini aksi pengguna disimulasikan lewat kode di bagian bawah (.click() = klik, dispatchEvent = ketik/tekan tombol). Tulis prediksi dulu, baru cek. Jika berbeda, cari tahu alasannya.

Latihan B — Koding bertahap

HTML dan CSS tidak diubah; jawaban ditulis di script.js. Di sini setiap soal punya halaman sendiri, jadi soal-soal tidak saling memengaruhi. B9–B12 ada di Tes Pengetahuan sebagai tantangan yang dinilai.

Mengerjakan di komputer sendiri? Bungkus tiap soal dengan kurung kurawal { ... } agar nama variabel tidak bentrok. Soal event tidak cukup dibuktikan dengan screenshot: kumpulkan rekaman layar singkat (10–15 detik) yang menunjukkan interaksinya.
