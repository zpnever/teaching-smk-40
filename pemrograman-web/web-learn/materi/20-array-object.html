Array & Object: Wadah untuk Banyak Data

Satu variabel untuk satu nilai sudah tidak cukup. Array menyimpan daftar berurutan, object menyimpan data berlabel — dan gabungan keduanya adalah bentuk data yang paling sering dipakai di aplikasi sungguhan.

Setelah ini kamu bisa:

  • Membuat array dan mengakses elemennya dengan index
  • Memakai push, pop, unshift, shift, includes, indexOf, join
  • Membuat object lalu mengakses, mengubah, menambah, dan menghapus property
  • Menggabungkan keduanya: array of object dan object bersarang
  • Mengirim array & object ke dalam function

1

PengenalanArray vs Object

Bayangkan kamu harus menyimpan nilai ulangan 30 siswa. Membuat nilai1, nilai2, … sampai nilai30 jelas melelahkan. JavaScript punya dua "wadah" untuk menyimpan banyak data sekaligus:

[ ]Array

Seperti rak berlaci bernomor. Isinya berurutan, setiap laci punya nomor (index).

{ }Object

Seperti kartu identitas. Setiap data punya label: nama, kelas, umur, ...

Array Object
Bentuk Daftar berurutan Kumpulan data berlabel (key: value)
Ditulis dengan [ ] { }
Mengakses lewat Nomor index (daftar[0]) Nama property (siswa.nama)
Cocok untuk Banyak data sejenis (daftar nilai, daftar nama) Satu benda dengan banyak sifat (profil siswa, produk)
Analogi Rak berlaci bernomor Kartu identitas
Setup file praktik

Seperti pertemuan sebelumnya, buat 2 file: index.html (struktur dasar HTML + <script src="./script.js">) dan script.js untuk koding. Di website ini kamu juga bisa langsung mencoba di editor.

Hampir semua data di aplikasi yang kamu pakai sehari-hari berbentuk array dan object: daftar chat, daftar produk di marketplace, daftar video, profil akun. Setelah materi ini, kamu bisa membaca bentuk data seperti itu.

Mengubah elemen & const pada array

Array yang dibuat dengan const isinya boleh diubah, tetapi variabelnya tidak boleh diganti seluruhnya. Analoginya: raknya dipaku ke dinding (tidak bisa diganti rak lain), tapi isi lacinya bebas ditukar.

ArrayMenambah & Menghapus Elemen

Dua pintu: awal & akhir
Method Fungsi Posisi Return (tambahan)
push(x) Menambah elemen Di akhir Panjang baru
pop() Menghapus elemen Di akhir Elemen yang dibuang
unshift(x) Menambah elemen Di awal Panjang baru
shift() Menghapus elemen Di awal Elemen yang dibuang
Tambahan: nilai yang dikembalikan

Method juga me-return sesuatu. pop() dan shift() mengembalikan elemen yang dibuang — berguna misalnya untuk mengambil antrean berikutnya.

Tambahan: splice untuk posisi di tengah

push/pop/shift/unshift hanya bekerja di ujung. Untuk menghapus atau menyisipkan di tengah, pakai splice(index, jumlahHapus, ...elemenBaru).

10

Method Modernmap, filter, find

Tambahan

Tiga method ini menerima callback dan sering menggantikan loop panjang. Semuanya tidak mengubah array asli.

Method Callback me-return Hasil
map(cb) Nilai baru untuk tiap elemen Array baru, panjang sama
filter(cb) true/false Array baru berisi elemen yang true
find(cb) true/false Elemen pertama yang true (atau undefined)
Pada array of object
Masih bingung? Tidak apa-apa memakai for...of biasa — hasilnya sama. map/filter/find hanya cara yang lebih ringkas, dan akan sering kamu jumpai di kode orang lain.
11

RingkasRangkuman

Array
const arr = ["a", "b", "c"];
arr[0];                 // "a"
arr.length;             // 3
arr[arr.length - 1];    // "c"
arr.push("d");          // tambah di akhir
arr.pop();              // hapus di akhir
arr.unshift("z");       // tambah di awal
arr.shift();            // hapus di awal
arr.includes("a");      // true
arr.indexOf("b");       // 1 (atau -1)
arr.join("-");          // "a-b-c"
Object
const obj = { nama: "Budi", umur: 16 };
obj.nama;               // "Budi"
obj["umur"];            // 16
obj.umur = 17;          // ubah
obj.kelas = "XI RPL";   // tambah
delete obj.umur;        // hapus
Object.keys(obj);       // ['nama', 'kelas']

// ARRAY OF OBJECT
const data = [{ nama: "Ani" }, { nama: "Budi" }];
data[1].nama;           // "Budi"
Tambahan Ingat
for...of / forEach Mengolah setiap elemen array
for...in Mengulang setiap nama property object
Array/object di function Bisa jadi argument & nilai return; data asli ikut berubah jika diubah di dalam
map / filter / find Ubah semua / saring / cari satu — tidak mengubah array asli

Aturan praktis

  1. Data sejenis dan berurutan → array. Data satu benda dengan banyak sifat → object.
  2. Index mulai dari 0; elemen terakhir arr[arr.length - 1].
  3. Array of object: index dulu, lalu property → data[1].nama.
