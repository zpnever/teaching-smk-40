Sejauh ini kode kita selalu jalan lurus dari atas ke bawah. Dengan percabangan, program bisa mengambil keputusan: kalau begini lakukan itu, kalau tidak lakukan yang lain.

  • Memahami nilai truthy & falsy, ternary, dan switch
  • Mengenali & memperbaiki kesalahan umum, lalu membangun program kasir toko

KonsepKonsep Percabangan

Alur percabangan
DefinisiPercabangan (conditional) adalah struktur yang membuat program menjalankan blok kode tertentu hanya jika suatu kondisi terpenuhi.

Kata kunci utamanya: kondisi itu selalu menghasilkan boolean (true atau false), persis seperti hasil operator perbandingan yang sudah kalian pelajari di pertemuan 16.

1Payung

Kalau hujan, bawa payung.

2Kantin

Kalau uang cukup, beli bakso. Kalau tidak, beli gorengan.

3Rapor

Nilai ≥ 90 dapat A, ≥ 80 dapat B, dan seterusnya.

Coba cari contoh "kalau… maka…" di aplikasi yang sering kamu pakai. Misalnya: kalau password salah, tampilkan pesan error. Semua itu percabangan!

SintaksPernyataan if

if menjalankan sebuah blok kode hanya jika kondisinya true. Jika false, blok tersebut dilewati.

Sintaks
Bagian Contoh Keterangan
Kata kunci if Menandai awal percabangan
Kondisi suhu > 30 Hasilnya harus boolean
Awal blok kode { Isi blok dijalankan jika kondisi true, ditutup dengan }
Contoh

Jalankan, lalu coba ganti 35 menjadi 25. Baris mana yang hilang?

3 aturan penting

  1. Kondisi diletakkan di dalam tanda kurung ( )
  2. Blok kode diapit kurung kurawal { }
  3. Indentasi (menjorok ke dalam) isi blok agar mudah dibaca

SintaksPernyataan if-else

Selalu ada tepat satu jalur

else menyediakan jalur alternatif ketika kondisi if bernilai false. Artinya, selalu ada tepat satu blok yang dijalankan.

Contoh penggunaan if-else

Operator modulus % menghasilkan sisa bagi. Bilangan genap jika sisa bagi 2 sama dengan 0.

Ubah angka menjadi 12, lalu 0, lalu -3. Program memilih jalurnya sendiri tanpa kamu mengubah if-nya.
4

SintaksPernyataan else if

Diperiksa dari atas

if-else hanya punya 2 jalur. Bagaimana jika ada lebih dari 2 kemungkinan? Misalnya predikat nilai: A, B, C, D. else if menambahkan kondisi tambahan yang diperiksa berurutan dari atas ke bawah.

Contoh penulisan kode
Urutan kondisi pada else if itu penting! Letakkan kondisi yang paling ketat (paling sulit dipenuhi) di paling atas.
5

LogikaKondisi Majemuk: &&, ||, !

Gabungkan beberapa syarat
Kilas balik operator logika

Operator logika dipakai untuk menggabungkan beberapa syarat dalam satu kondisi.

Operator Nama Hasil true jika
&& AND Kedua kondisi true
|| OR Salah satu kondisi true
! NOT Kondisi aslinya false (membalik nilai)
Contoh dengan || (Bioskop)

Boleh masuk jika sudah 17 tahun atau didampingi orang tua.

Contoh dengan && (Syarat Kelulusan)

Lulus jika nilai akhir minimal 75 dan kehadiran minimal 80.

Nilainya sudah 80, kenapa tetap tidak lulus? Karena && menuntut semua syarat terpenuhi, dan kehadiran 70 belum mencapai 80.
6

StrukturNested if (if Bersarang)

if di dalam if

Nested if adalah if yang berada di dalam blok if atau else lainnya. Dipakai ketika sebuah pengecekan baru boleh dilakukan setelah pengecekan sebelumnya terpenuhi.

Nested if vs operator &&

Pada kasus tertentu, nested if bisa diganti &&. Bedanya: versi && lebih ringkas, tapi tidak bisa memberi pesan berbeda untuk username salah dan password salah.

Jangan membuat nested if lebih dari 3 tingkat. Jika sudah terlalu dalam, pertimbangkan menyederhanakannya dengan && atau else if.
7

KonsepTruthy dan Falsy

Semua nilai bisa jadi kondisi

Kondisi if tidak harus selalu berupa perbandingan. JavaScript bisa menganggap nilai apa pun sebagai true atau false ketika dipakai di dalam kondisi.

Nilai Falsy dianggap false

Hanya 6 nilai ini: false, 0, "" (string kosong), null, undefined, NaN.

Nilai Truthy dianggap true

Semua nilai selain yang disebut di atas. Contoh: "halo", 5, -1, true.

Kegunaan nyata: mengecek apakah sebuah isian sudah diisi. Ganti nama menjadi string kosong "" lalu jalankan lagi.

8

RingkasOperator Ternary

Operator ternary adalah cara singkat menulis if-else sederhana dalam satu baris. Disebut "ternary" karena memiliki 3 bagian: kondisi, hasil jika benar, dan hasil jika salah.

Sintaks
Contoh
if-else (5 baris) Ternary (1 baris)
let status; if (umur >= 17) { status = "Dewasa"; } else { status = "Anak-anak"; } let status = umur >= 17 ? "Dewasa" : "Anak-anak";
Ternary cocok untuk kondisi sederhana dengan 2 kemungkinan hasil. Kalau sudah lebih dari itu, pakai if / else if supaya tetap mudah dibaca.
9

SintaksPernyataan switch

Tambahan
Pilih satu dari banyak

switch cocok saat kamu membandingkan satu nilai dengan banyak kemungkinan nilai pasti (misalnya nomor hari, kode menu). Setiap kemungkinan ditulis sebagai case, dan default dijalankan kalau tidak ada yang cocok.

Jangan lupa break;! Tanpa break, setelah menemukan case yang cocok, JavaScript akan terus menjalankan case-case di bawahnya. Coba hapus satu break di atas lalu jalankan.
Beberapa case, satu aksi

Case boleh ditumpuk kalau aksinya sama. switch membandingkan dengan === (ketat), jadi tipe datanya harus sama persis.

switch atau else if?
Pakai Ketika Contoh
switch Mencocokkan satu nilai dengan daftar nilai pasti nomor hari, pilihan menu 1/2/3, kode kelas
else if Kondisinya berupa rentang atau gabungan syarat nilai >= 80, umur >= 17 && punyaKTP
10

DebuggingKesalahan Umum pada Percabangan

Tambahan
Temukan bug-nya

Kode yang terlihat benar kadang menghasilkan output aneh. Berikut 4 kesalahan yang paling sering terjadi. Jalankan tiap contoh, lihat hasilnya, lalu baca cara memperbaikinya.

Satu = adalah penugasan (mengisi nilai), bukan perbandingan. Kondisinya jadi bernilai 100 (truthy), dan variabelnya ikut berubah!

Perbaikan: pakai === untuk membandingkan: if (nilai === 100).

Kondisi yang longgar diletakkan paling atas, sehingga kondisi yang lebih ketat tidak pernah tercapai. Nilai 95 malah dapat C!

Perbaikan: urutkan dari yang paling ketat: >= 90, lalu >= 80, lalu >= 70.

Titik koma setelah if (...) membuat if-nya "kosong". Blok { } di bawahnya jadi blok biasa yang selalu dijalankan.

Perbaikan: hapus ; setelah tanda kurung kondisi. Ingat: tidak ada titik koma di antara ) dan {.

Tanpa kurung kurawal, hanya satu baris pertama yang ikut if. Baris berikutnya selalu jalan walau indentasinya menjorok.

Perbaikan: selalu bungkus isi if dengan { }, walaupun isinya hanya satu baris.

Kalau output-mu aneh, baca kode baris demi baris sambil "menjadi komputer": hitung nilai kondisinya satu per satu, true atau false?

Studi KasusProgram Kasir Toko

Tambahan
Diskon otomatis

Saatnya merakit semua yang sudah dipelajari menjadi program nyata: kasir toko yang menentukan diskon secara otomatis. Sebelum menulis kode, pecah masalahnya dulu:

1Data apa?

totalBelanja (number) dan isMember (boolean).

2Aturan apa?

Urutkan dari yang paling ketat: belanja besar dulu, baru status member, terakhir sisanya.

3Output apa?

Persentase diskon dan jumlah yang harus dibayar.

Polanya: siapkan variabel hasil dengan nilai awal (let diskon = 0;), ubah nilainya di dalam percabangan, lalu pakai setelah percabangan selesai.

RingkasRangkuman

Struktur Fungsi Contoh Singkat
if Jalankan blok hanya jika kondisi true if (suhu > 30) { ... }
if-else Dua jalur: benar atau salah if (...) { ... } else { ... }
else if Banyak jalur, diperiksa berurutan if ... else if ... else
Kondisi majemuk Gabungkan syarat dengan &&, ||, ! if (a >= 75 && b >= 80)
Nested if if di dalam if Login: cek username lalu password
Truthy / Falsy Nilai apa pun bisa dipakai sebagai kondisi if (nama) { ... }
Ternary Versi singkat if-else untuk 2 jalur a ? b : c
switch Satu nilai dicocokkan dengan banyak case switch (hari) { case 1: ... }

Ingat selalu

  • Bandingkan dengan ===, bukan =.
  • Urutkan else if dari kondisi paling ketat.
  • Tidak ada ; di antara ) dan {, dan selalu pakai { }.
  • Falsy hanya 6: false, 0, "", null, undefined, NaN.
