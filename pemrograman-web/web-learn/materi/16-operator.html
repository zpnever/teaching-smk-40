Menghitung & Membandingkan dengan Operator

Operator adalah "kata kerja" di JavaScript: menjumlah, membandingkan, menggabungkan, sampai mengubah tipe data. Tanpa operator, data di variabel cuma diam saja.

Setelah ini kamu bisa:

  • Menggunakan operator aritmatika dan memahami prioritas operasi
  • Menggunakan operator penugasan, termasuk ++ dan --
  • Membedakan operator perbandingan == dan ===
  • Menggunakan operator logika &&, ||, ! beserta tabel kebenarannya
  • Menulis ternary sebagai if-else singkat dan mengonversi tipe data secara eksplisit

MenghitungOperator Aritmatika

Modulus = sisa bagi

Digunakan untuk melakukan perhitungan matematika terhadap nilai number.

Operator Nama Contoh Hasil
+ Penjumlahan 10 + 3 13
- Pengurangan 10 - 3 7
* Perkalian 10 * 3 30
/ Pembagian 10 / 3 3.333...
% Modulus (sisa bagi) 10 % 3 1
** Pangkat 2 ** 3 8
Modulus % sering dipakai untuk mengecek genap/ganjil: kalau angka % 2 hasilnya 0, angkanya genap. Ini akan sangat berguna di pertemuan percabangan & perulangan.
3

UrutanPrioritas Operator (Precedence)

Siapa duluan?

Sama seperti matematika, JavaScript mengikuti urutan prioritas:

  1. Tanda kurung ( )
  2. Pangkat **
  3. Perkalian *, pembagian /, modulus %
  4. Penjumlahan +, pengurangan -

Jika prioritasnya setingkat (misalnya % dan *), dikerjakan dari kiri ke kanan.

Ragu dengan urutannya? Pakai tanda kurung. (a + b) * c jauh lebih jelas dibaca teman satu tim daripada menghafal tabel prioritas.

+ suka menggabung teks
Penggabungan (concatenation)

Operator + yang sama juga bisa dipakai untuk menggabungkan string.

Type coercion: konversi otomatis
DefinisiType Coercion adalah konversi tipe data yang dilakukan otomatis oleh JavaScript tanpa diminta programmer.
Coercion sering bikin bug yang sulit dicari. Di bagian Konversi Tipe Data kamu akan belajar mengubah tipe secara sengaja supaya hasilnya pasti.
5

MengisiOperator Penugasan & Increment

Operator penugasan mengisi atau memperbarui nilai variabel. Bentuk gabungannya adalah cara singkat menulis perhitungan lalu menyimpannya kembali.

Operator Contoh Sama dengan
= x = 5 Isi x dengan 5
+= x += 3 x = x + 3
-= x -= 3 x = x - 3
*= x *= 3 x = x * 3
/= x /= 3 x = x / 3
%= x %= 3 x = x % 3
Increment & decrement

++ menambah 1, -- mengurangi 1. Ini akan sering kamu pakai di perulangan (i++).

Prefix vs postfix

Posisi ++ berpengaruh kalau nilainya langsung dipakai. a++ (postfix) memakai nilai lama dulu, baru menambah. ++b (prefix) menambah dulu, baru dipakai.

6

MembandingkanOperator Perbandingan & == vs ===

Nilai sama, tipe beda

Operator perbandingan menghasilkan nilai boolean (true/false).

Operator Arti Contoh Hasil
== Sama dengan (nilai) 5 == "5" true
=== Sama dengan (nilai dan tipe) 5 === "5" false
!= Tidak sama (nilai) 5 != 3 true
!== Tidak sama (nilai dan tipe) 5 !== "5" true
> Lebih besar 7 > 3 true
< Lebih kecil 7 < 3 false
>= Lebih besar atau sama 5 >= 5 true
<= Lebih kecil atau sama 4 <= 3 false
== vs === (sangat penting!)

Aturan praktis (wajib diingat)

Selalu gunakan === dan !==, hindari == dan !=, agar tidak terjadi hasil yang tidak terduga.

Jangan tertukar: = untuk mengisi variabel, === untuk membandingkan. x = 5 mengubah x, sedangkan x === 5 hanya bertanya "apakah x sama dengan 5?".

Menggabung syaratOperator Logika

AND seri, OR paralel

Digunakan untuk menggabungkan beberapa kondisi boolean menjadi satu hasil boolean.

Operator Nama Arti Contoh Hasil
&& AND Benar jika kedua sisi benar true && false false
|| OR Benar jika salah satu benar true || false true
! NOT Membalik nilai boolean !true false
Tabel kebenaran
A B A && B A || B
true true true true
true false false true
false true false true
false false false false
Ibarat izin keluar rumah: && = harus diizinkan ayah dan ibu. || = cukup diizinkan ayah atau ibu.

If-else singkatOperator Ternary

Dua jalan, satu pilihan

Operator ternary adalah cara singkat menulis if-else sederhana dalam satu baris. Disebut "ternary" karena punya 3 bagian: kondisi, hasil jika benar, dan hasil jika salah.

Sintakskondisi ? nilaiJikaBenar : nilaiJikaSalah
Pakai ternary hanya untuk kondisi sederhana dengan 2 kemungkinan hasil. Kalau sudah lebih rumit, gunakan if-else yang akan dipelajari di pertemuan 17.

Mengubah tipeKonversi Tipe Data (Type Conversion)

Ubah tipe dengan sengaja
DefinisiType Conversion adalah proses mengubah nilai dari satu tipe data ke tipe data lain secara sengaja oleh programmer (berbeda dengan type coercion yang terjadi otomatis).
Mengapa perlu?

Input dari pengguna (misalnya dari form HTML) selalu berbentuk string, meskipun terlihat seperti angka. Jika langsung dihitung tanpa dikonversi, hasilnya bisa salah.

Number(): string → number
String(): number → string
Boolean(): nilai → boolean

Falsy dianggap false

0, "" (string kosong), null, undefined, NaN (dan tentu false)

Truthy dianggap true

Selain nilai di sebelah. Termasuk "0", " " (spasi), dan -1!

Tambahan: parseInt(), parseFloat() & toFixed()

parseInt() dan parseFloat() membaca angka dari awal teks dan berhenti saat ketemu huruf. Cocok untuk teks seperti "12px". Sedangkan toFixed(n) membulatkan ke n angka di belakang koma — tapi hasilnya string.

Alat bantuObjek Math

Tambahan
Angka acak untuk game

JavaScript punya "kotak perkakas" bernama Math berisi fungsi matematika siap pakai. Ini sering dipakai untuk pembulatan nilai dan membuat angka acak di game.

Fungsi Kegunaan Contoh Hasil
Math.round() Bulatkan ke terdekat Math.round(4.5) 5
Math.floor() Bulatkan ke bawah Math.floor(4.9) 4
Math.ceil() Bulatkan ke atas Math.ceil(4.1) 5
Math.max() Nilai terbesar Math.max(3, 9, 2) 9
Math.min() Nilai terkecil Math.min(3, 9, 2) 2
Math.random() Angka acak 0 sampai < 1 Math.random() 0.7302…
Jalankan kode di atas beberapa kali — angka dadunya berubah-ubah! Rumus Math.floor(Math.random() * n) + 1 menghasilkan angka acak dari 1 sampai n.
